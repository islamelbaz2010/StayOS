# StayOS Supply Outreach Scripts

**Posture:** These are READY_TO_SEND templates. Replace [BRACKETS] with actual values before sending.
**Sender:** Founder only. Never automate, never bot-send.
**Language:** Arabic first, English second where noted.

## §W1 — WhatsApp: Individual Owner (First Contact)

**Use for:** DISC_001–DISC_009 (discovery candidates), PNET_001–PNET_010, OLX_001+, FB_001+

**Arabic Version (primary):**
```
السلام عليكم [الاسم]،

أنا إسلام، مؤسس StayOS — منصة مصرية للإيجار اليومي والأسبوعي في التجمع الخامس والرحاب.

بنبني أول منصة محلية متخصصة في الإيجار المرن للشقق المفروشة في القاهرة الجديدة.

كنت بتواصل معاك عشان شوفت إن عندك وحدة/شقة في المنطقة دي — ومحتاج عدد محدود من الملاك الأوائل (10 فقط) اللي يضيفوا عقاراتهم على المنصة.

مش هتحتاج تعمل أي حاجة تانية غير إنك تديني التفاصيل والصور — هوضبها أنا على المنصة، وهتبدأ تستقبل حجوزات.

العمولة 0% على أول 3 حجوزات.

ممكن تقولي هل الشقة متاحة للإيجار اليومي أو الأسبوعي؟
```

**English Version (if owner responds in English):**
```
Hi [Name],

I'm Islam, founder of StayOS — Egypt's first dedicated short-term rental platform for New Cairo (5th Settlement / Rehab).

I'm reaching out because I noticed your property in the area. We're onboarding our first 10 host partners and I'd love to include your unit.

What this means for you:
- Your property listed on StayOS with full Arabic/English support
- 0% commission for your first 3 bookings
- I personally handle the setup — you just share details and photos

Is your unit available for short-term stays?
```

**When to use which:** If you found them via Arabic platform (OLX, Facebook Marketplace in Arabic) → use Arabic first. If via Google Maps listing in English or personal network friend → start with English or whatever you'd normally speak.

## Sending Rules

| Rule | Detail |
|------|--------|
| Never send twice the same day | One message per 24h maximum per lead |
| Personal network = informal first | Don't open with a formal script — start with "hey, question..." |
| Agency = formal + email + follow up by phone | Multiple touchpoints expected |
| Never claim the platform is live unless it is | Say "launching soon" or "in final prep" |
| Never send group messages | Every message is 1:1 |
| Log every send in SUPPLY_TRACKER.csv | Contact_Date = date sent, Contact_Status = CONTACTED |
