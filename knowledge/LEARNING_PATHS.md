# Learning Paths — StayOS Knowledge Base

**Purpose**: Role-based reading sequences for new team members and cross-functional learning.
**Last Updated**: 2026-07-27

---

## How to Use Learning Paths

Each path below is a sequenced reading program. Read in order — each article builds on the previous. After completing a path, you can use the KNOWLEDGE_INDEX.md to explore specific topics more deeply.
