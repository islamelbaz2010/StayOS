# 05 — ALPHA SUCCESS SCORECARD

**Author:** Executive Program Director & Chief Product Officer  
**Date:** 2026-08-03  
**Status:** LOCKED — These are the ONLY metrics that decide success. Everything else is vanity.

---

## The 10 KPIs

### 1. Live Listings in New Cairo

| Field | Value |
|-------|-------|
| **Why it matters** | Without supply, there is no marketplace. This is the #1 leading indicator. |
| **Target** | 40 by Week 6 |
| **Measurement** | Count of listings with status=LISTED in New Cairo (5th Settlement, Rehab, compounds) |
| **Action if below target** | If < 20 by Week 4: founder drops all other work and does manual seeding. If < 30 by Week 6: extend alpha to 8 weeks. |
| **Owner** | Founder |
| **Review frequency** | Daily |

---

### 2. Completed Bookings

| Field | Value |
|-------|-------|
| **Why it matters** | This is the transaction. It proves the marketplace loop works end-to-end. |
| **Target** | 7 by Week 6 (10 if supply reaches 50) |
| **Measurement** | Count of reservations with status=CHECKED_OUT |
| **Action if below target** | If < 3 by Week 5: founder personally guarantees 5 bookings. Offers 25% discount. Personally matches guests to listings. If < 5 by Week 6: extend alpha. |
| **Owner** | Founder |
| **Review frequency** | Daily |

---

### 3. Payment Collected in EGP

| Field | Value |
|-------|-------|
| **Why it matters** | No payment = no transaction = no business. Payment must work in local currency. |
| **Target** | 100% of completed bookings |
| **Measurement** | Count of bookings where payment_status=PAID and currency=EGP |
| **Action if below target** | If any booking has uncollected payment: founder contacts guest, resolves within 24 hours. If Paymob is down: switch to manual confirmation permanently for alpha. |
| **Owner** | Founder |
| **Review frequency** | Per booking |

---

### 4. Verified Hosts

| Field | Value |
|-------|-------|
| **Why it matters** | Verified supply is the trust differentiator. Unverified listings are not a marketplace — they're a directory. |
| **Target** | 12 by Week 6 (100% of hosts with live listings) |
| **Measurement** | Count of users with role=HOST and kyc_status=VERIFIED who own at least 1 LISTED listing |
| **Action if below target** | If < 8 by Week 4: founder prioritizes KYC review over everything else. Target < 4 hour review time. |
| **Owner** | Founder |
| **Review frequency** | Daily |

---

### 5. Guest Differentiation Perception

| Field | Value |
|-------|-------|
| **Why it matters** | This is the vision test. If guests cannot identify why StayOS is different from Airbnb, the MVP has failed its purpose. |
| **Target** | >= 70% of surveyed guests cite at least 1 StayOS differentiator |
| **Measurement** | Post-booking WhatsApp survey: "ليه اخترت StayOS مش Airbnb؟" (Why did you choose StayOS over Airbnb?) Code responses: Arabic-first, cultural filters, trust signals, local payment, lower price, founder relationship. |
| **Action if below target** | If < 50%: vision features are insufficient. Add more visible differentiators (Arabic FAQ, host profile page, "Why StayOS" section on landing page). |
| **Owner** | Founder |
| **Review frequency** | Per guest (after checkout) |

---

### 6. Host Payout Speed

| Field | Value |
|-------|-------|
| **Why it matters** | Fast payout is a competitive advantage over Airbnb. If payout is slow, hosts churn. |
| **Target** | 100% of payouts within 48 hours of checkout |
| **Measurement** | For each completed booking: time from checkout to payout confirmation. Track in spreadsheet. |
| **Action if below target** | If any payout exceeds 48 hours: founder calls host, explains delay, processes immediately. If > 2 payouts exceed 48 hours: review payout process. Simplify. |
| **Owner** | Founder |
| **Review frequency** | Per payout |

---

### 7. Fraud Incidents

| Field | Value |
|-------|-------|
| **Why it matters** | One fraud incident destroys trust. Trust is the differentiator. Zero tolerance. |
| **Target** | 0 |
| **Measurement** | Count of confirmed fraud incidents (fake listing, stolen payment, identity theft, property misrepresentation) |
| **Action if below target** | N/A — target is zero. If any fraud occurs: suspend involved listing/account immediately. Investigate within 24 hours. Report to committee. Review KYC and listing review process. |
| **Owner** | Founder |
| **Review frequency** | Per incident (immediate) |

---

### 8. Search-to-Booking Conversion

| Field | Value |
|-------|-------|
| **Why it matters** | Measures whether guests who search actually book. If conversion is near zero, either supply is wrong or the booking flow is broken. |
| **Target** | >= 3% (completed bookings / total searches) |
| **Measurement** | Analytics: count of search page views vs. completed bookings. For alpha, use manual tracking: founder logs every search and every booking. |
| **Action if below target** | If < 1%: check if search results are too thin (< 5 results). Check if booking flow has friction. Founder sends direct links to guests instead of relying on search. |
| **Owner** | Founder |
| **Review frequency** | Weekly |

---

### 9. Host Retention (Active After 2 Weeks)

| Field | Value |
|-------|-------|
| **Why it matters** | Hosts who don't get bookings in 2 weeks lose interest and churn. Retention requires active management. |
| **Target** | >= 60% of hosts with listings live for 2+ weeks have received at least 1 booking inquiry |
| **Measurement** | Count of hosts with LISTED listings for 2+ weeks who have received at least 1 booking or inquiry / total hosts with LISTED listings for 2+ weeks |
| **Action if below target** | If < 40%: founder personally finds a guest for every host who hasn't received an inquiry. Call every host. Offer to adjust price. |
| **Owner** | Founder |
| **Review frequency** | Weekly |

---

### 10. Founder Time on Host Recruitment

| Field | Value |
|-------|-------|
| **Why it matters** | If founder spends < 2 hours/day on host recruitment, supply will stall. This is the leading indicator for KPI #1. |
| **Target** | >= 2 hours/day on host outreach calls |
| **Measurement** | Founder self-reports in daily log. Track in spreadsheet. |
| **Action if below target** | If < 2 hours for 3 consecutive days: delegate operations work to ops hire. Block calendar for host calls. Non-negotiable. |
| **Owner** | Founder |
| **Review frequency** | Daily |

## Metrics NOT Tracked (Vanity Metrics)

These are explicitly excluded. Do not track, report, or optimize for them during alpha:

- Total page views
- Total unique visitors
- Social media followers
- Email list size
- Total signups (without listing or booking)
- App store ratings
- Press mentions
- Total downloads
- Time on site
- Bounce rate
- Number of features shipped

**If a metric is not on this scorecard, it does not matter during alpha.**
